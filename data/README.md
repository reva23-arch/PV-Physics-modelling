# Data

The dataset used in this project is PVDAQ System 1433 from the NREL Research Support Facility in Golden, Colorado.

Source:

https://data.openei.org/submissions/4568

## Dataset used

The analysis used measurements from January 2018, sampled at 15-minute intervals.

The variables used were:

- POA irradiance
- Ambient temperature
- Module temperature
- AC power

The analysis selected 14 days of data and filtered observations to retain valid AC power measurements and POA irradiance above 20 W/m².

The final dataset used for modelling contained 374 observations.

## Data availability

The original dataset is not included in this repository. Please obtain the data directly from the source above.
